# SmartLab Inventory Frontend

React/Vite frontend for the existing SmartLab Inventory backend.

## Setup

1. Put this folder as your `frontend` folder, or copy its `src`, `index.html`, and package.json into your existing Vite frontend.
2. From the frontend folder:
   `npm install`
3. Start:
   `npm run dev`
4. Backend must be running at:
   `http://localhost:5000`

## Demo modules

1. Authentication & Authorization
2. Inventory Management
3. Component Requests & Issue/Return
